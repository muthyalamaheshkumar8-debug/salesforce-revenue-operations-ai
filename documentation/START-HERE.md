# Open the updated project
1. Extract the ZIP. Open `dashboard.html` in a modern browser for a portable local dashboard with all 13 views and the full bundled snapshot. No installation is needed for local UI practice.
2. Open **Integrations** to see all 16 requirement statuses and their next verification steps.
3. Open **Sales enablement** for the knowledge repository and assessments. Use search/audience filters; export a practice record after completing a course.
4. Open **Engagement** and select Gong/Apollo/Outreach/Salesloft. Load a labeled practice example or upload normalized JSON per `integrations/engagement-contract.json`. Review matching errors and export the results.
5. Open **New business** to dry-run the legacy mapping. The mapped export is gated on a non-empty, exception-free batch.
6. Open **Payout review** to calculate, review and approve a local scenario. **Team handoff** includes developer tickets and Sales/CSM/Marketing briefs. Nothing is sent or paid.
7. For durable shared role/audit workflows, run the included FastAPI backend privately and follow `operations-api.md`. The public/offline dashboard's local rehearsal does not authenticate or call that backend.

These additions are in this updated ZIP. Use the GitHub/live-site links in README.md for the published operations update. Native platform runs, real trainees and real collaborators remain unverified. UI inputs are session-local; use the export buttons to retain your own practice results.
